# Castle Defender

Mobilna gra 2D pixelart (Android) z asynchronicznym PvP. Gracze rozbudowują zamki od wałów ziemnych przez kamienne mury do twierdzy z końca wojen napoleońskich, a potem atakują zamki innych graczy. Gdy gracz jest offline, jego zamek broni się według ustawionej taktyki. Bez zewnętrznych assetów, cała grafika rysowana kodem.
